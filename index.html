Tee Inbox Agent

A personal command-line tool that files notification noise out of my own Gmail inboxes. It runs on my laptop, it has exactly one user, and it is not a product.

What it is

Tee Inbox Agent is a small set of Python scripts I wrote for myself. Email newsletters, shipping notices, receipts and marketing blasts pile up faster than I can sort them by hand, so the tool looks at who is sending me the most mail, proposes a label and a Gmail filter for each repeat sender, and — once I approve the list — creates those labels and filters and files the existing backlog.

That is the whole scope. It is a chore automator for two mailboxes that belong to me.

Not available to anyone else. There is no sign-up, no hosted service, and no shared instance. The tool authorizes only against my own Google Accounts and runs only on my own machines.

How it works

  • I run it manually from a terminal. There is no background service and no scheduled job.
  • It talks directly to the Gmail API from my laptop. There is no backend server of mine in between.
  • It reads message headers only — sender, subject line, and the List-Id / List-Unsubscribe headers that identify bulk mail. It does not download message bodies or attachments.
  • It writes back only inbox organization: it creates labels, creates Gmail filters, applies labels, archives, and marks messages read. It can route mail from a sender I have confirmed as a scam into Spam or Trash.
  • It never composes, sends, forwards, or replies to mail, and it never permanently deletes anything.

Why it asks for Gmail permissions

Google requires an app to request named permission scopes. This one requests two:

  • gmail.modify — to read message headers and to apply, remove, and manage labels (archiving and marking-as-read are label operations in Gmail).
  • gmail.settings.basic — to create the Gmail filters that keep doing the work after the tool has exited.

Those permissions are granted by me, to a tool on my own computer, against my own mailboxes.
