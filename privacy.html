Privacy Policy

Tee Inbox Agent · last updated 6 October 2026

Who this covers

Tee Inbox Agent is a personal command-line tool written and operated by Tee DosSantos. It has one user: me. It authorizes against my own Google Accounts (teedossantos@gmail.com and tee@teedossantos.com) and runs only on computers I own. It is not offered to, sold to, or usable by anyone else, and it collects no data from anyone other than me.

This policy is published because Google requires every application using the Gmail API to have one. It describes, accurately, what the tool does.

What the tool accesses

The tool requests two Google OAuth scopes:

  • https://www.googleapis.com/auth/gmail.modify — read message metadata and apply or remove labels.
  • https://www.googleapis.com/auth/gmail.settings.basic — create Gmail filters.

Within those scopes it reads only:

  • Message IDs and label IDs for messages in my inbox.
  • Four message headers, requested explicitly: From, Subject, List-Unsubscribe, and List-Id.

It requests message metadata only. It does not fetch, download, store, or display message bodies, attachments, images, or any other header.

What the tool does with it

It counts how many messages each sender has sent over a chosen window and prints that summary to my terminal. I read the summary and decide which senders should be filtered. On my approval, the tool:

  • creates Gmail labels, if they do not already exist;
  • creates Gmail filters matching those senders;
  • applies labels to existing messages, removes them from the inbox, and marks them read;
  • for a sender I have specifically confirmed as a scam, marks existing mail as Spam and files future mail to Trash.

It does not, under any circumstance:

  • send, compose, forward, or reply to email;
  • permanently delete email;
  • read, parse, or store message bodies or attachments;
  • change account settings beyond labels and filters;
  • touch any mailbox other than my own two.

Where data is stored

There is no server, no hosted backend, no database, and no cloud storage associated with this tool. It runs as a local process on my own machine and talks directly to the Gmail API.

  • OAuth tokens are written to a private directory on my machine (~/.config/secrets/gmail/), with file permissions restricted to my user account. They are never transmitted anywhere except to Google during the normal OAuth flow.
  • Message metadata is held in memory for the duration of a run and printed to my terminal. It is not written to any persistent store by the tool.
  • No message content is stored at all, because none is ever retrieved.

Sharing and transfer

No Google user data obtained through this tool is shared with, transferred to, or disclosed to any other person, company, service, or system. There are no analytics, no telemetry, no error-reporting services, no advertising, and no third-party integrations. The data is not used to develop, improve, or train any artificial-intelligence or machine-learning model.

Limited Use

Tee Inbox Agent's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and revocation

Access can be withdrawn at any time by revoking the tool's access at myaccount.google.com/permissions, which immediately invalidates its tokens. Deleting the local token files has the same practical effect on my machine. Labels and filters the tool has already created remain in my Gmail account until I remove them, exactly as if I had created them by hand.

Children

The tool is not directed at children and has no users other than its author.

Changes

If the tool's behavior changes, this page is updated to match before the change is used. The date at the top reflects the most recent revision.
